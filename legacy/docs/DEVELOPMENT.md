# 开发阶段与平台范围

项目名称待定。目标是在现有开源应用基础上开发独立维护的三维人体学习工具，支持 Windows、macOS、Linux 与 Web。正式命名前，界面以“三维图谱 / 3D atlas”描述功能，不设计或宣称一个已确定的品牌。版权与上游来源见 [NOTICE.md](../NOTICE.md)。

## 当前技术边界

React / TypeScript 负责共享界面和交互；Three.js 负责模型、相机与渲染；Vite 构建 Web 和桌面前端。Windows、macOS 与 Linux 桌面共享 Tauri / Rust 原生壳。平台专属能力集中在 `client/platform/` 与 `src-tauri/`。

网页版、桌面前端构建与 Linux 原生客户端已有验证基础。Windows、macOS 原生包仍需各自平台的构建和实机验证；不得用前端构建成功代替原生平台验收。现有 Linux Releases 属于此前的平台扩展阶段，保留原名称。

## 第一项交互优化：保留观察视角

切换系统或结构显隐时，保留用户相机位置、方向、观察中心与缩放。清除结构选择、关闭侧栏和普通窗口尺寸变化不应将视角重置为预设角度。分离布局重新计算也应保留当前视角。主动定位结构、切换预设视角、重置视角和调整分离程度仍执行对应的取景行为。

主要实现位于 `app/scene.tsx`。浏览器回归测试使用真实 Three.js 相机，覆盖普通视图、结构聚焦后的隐藏肌肉、侧栏关闭、窗口尺寸变化、分离视图，以及主动重置后保留图层状态。测试在浏览器收到的模块响应中获取相机引用，不在发布应用中开放调试接口。

```sh
npm ci
npm run dev
npm run ci:check
# 浏览器相机回归测试，需本机已安装 Chromium/Chrome：
CHROMIUM_PATH=/usr/bin/chromium npm run validate:camera
```
